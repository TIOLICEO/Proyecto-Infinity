## 2. INFRAESTRUCTURA FÍSICA Y HARDWARE (La Red Mesh)
La red comienza entre celulares de particulares conectados directamente entre sí (Peer-to-Peer) utilizando BLE y Wi-Fi Direct. El "salto" (hopping) permite que un mensaje viaje a su destino usando dispositivos intermedios de forma 100% encriptada.

Para potenciar la red celular, se despliegan nodos dedicados:
*   **Nodo G1 (Home):** Hardware residencial "Plug & Earn" (ESP32-S3 + LoRa).
*   **Nodo G2 (Urban):** Repetidores urbanos (IP67) en alumbrado público.
*   **Nodo G3 (Tower):** Bases de alta potencia alimentadas por energía solar.
*   **Infinity Orbit:** Constelación Nano-Satelital (LEO) con enlace láser inter-satelital.
